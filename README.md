<p>OICPP IDE 起源于一个退役高中 OIer 对信息学竞赛的热爱与对编程工具的思考。</p>

<p>OICPP-Plus IDE 是独立的 fork 项目，也起源于一个现役初中 OIer 对信息学竞赛的热爱与对编程工具的思考。</p>

<p>OICPP-Plus 在保持与 OICPP 功能完全对齐的基础上，对性能、安全性、稳定性和开发者体验做了进一步提升。</p>
<br>

## 支持的功能

- [x] 中英双语支持
- [x] 代码编辑与运行
- [x] 多标签页支持
- [x] 深浅主题切换与代码高亮
- [x] 自定义编辑器背景图片与窗口透明度
- [x] 支持自定义配色 
- [x] 代码补全
- [x] 工作区文件快速搜索 
- [x] 一键下载编译器、testlib 并自动配置
- [x] 预设文件模板与关键字模板
- [x] 内置浏览器 
- [x] 样例测试器（支持文件大样例）
- [x] 代码对拍器（支持差异高亮与数据导出）
- [x] 调试
- [x] 基于浏览器插件的 atcoder、cf、luogu、hetao 样例抓取
- [x] 分屏与查看 PDF
- [x] markdown 侧边预览
- [x] 云编译（暂不可用），可一键测试代码在 Linux 下能否通过编译
- [x] 云空间（暂不可用），可在设备间便捷的同步代码 
- [x] 支持 NOI Linux（暂不可用）
- [x] 支持内置终端
- [x] 文件历史记录与标签页自动恢复 

## 云服务说明

OICPP-Plus 的云同步、云编译、账号认证、更新检查、日志上传等云服务目前**暂不可用**（尚未部署独立的云服务，为避免误用 OICPP 官方的服务器资源，已在前端禁用相关功能入口）。本 fork 与 OICPP 官方无服务关联，代码可在本地独立使用。
